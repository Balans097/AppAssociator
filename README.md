# AppAssociator
AppAssociator — утилита для Windows 11 (в т.ч. 24H2 LTSC), перенаправляющая вызовы классического Paint (mspaint.exe / ProgID PBrush) на XnView. Иначе говоря, приложение перенаправляет запуск классического приложения Paint (`mspaint.exe`) на сторонний просмотрщик/редактор изображений **XnView**.

По мере необходимости, AppAssociator будет доработан для установления ассоциаций с другими проблемными приложениями Windows 11.

## Что делает программа

Программа изменяет две ключевые ветки реестра в разделе  
`HKEY_CURRENT_USER\Software\Classes`, чтобы перехватить вызовы Paint:

1. **ProgID PBrush**  
   - Путь: `Software\Classes\PBrush\shell\open\command`  
   - Изменяет команду запуска на:  
     `"путь_к_XnView.exe" "%1"`

2. **Приложение mspaint.exe**  
   - Путь: `Software\Classes\Applications\mspaint.exe\shell\open\command`  
   - Также перенаправляет на XnView

### Дополнительно

- Устанавливает иконку XnView для этих ассоциаций  
- Вызывает `SHChangeNotify`, чтобы Windows сразу обновила ассоциации (без перезагрузки)

## Результат

Файл будет открываться в **XnView** вместо стандартного Paint в следующих случаях:

- Двойной клик по файлу .jpg, .png и др., для которых по умолчанию стоит Paint  
- Запуск «Paint» через меню «Пуск», поиск Windows или команду `mspaint`  
- Открытие изображения через контекстное меню → **«Открыть с помощью» → Paint**

## Важные замечания

- Работает **только для текущего пользователя** (HKEY_CURRENT_USER)  
  → **не требует прав администратора**
- Требует правильного указания пути к XnView в константе `XNVIEW_PATH`
- Если после перезагрузки / обновления Windows ассоциации «слетают» обратно на Paint →  
  при следующем запуске изображения **всё равно откроется XnView**  
  (перехват происходит на уровне ProgID и exe-приложения)
- **Не меняет** глобальные ассоциации файлов (*.jpg, *.png и т.д.) — только вызовы Paint

## Использование

1. Убедитесь, что XnView установлен  
   → проверьте и при необходимости исправьте путь в константе `XNVIEW_PATH`
2. Скомпилировать программу:

   ```bash
   # консольная версия
   nim c -d:release AppAssociator.nim

   # версия без консоли (GUI)
   nim c -d:release --app:gui AppAssociator.nim
